# 🤝 Contributing to Briefly

Thanks for your interest in contributing to **Briefly**! We welcome all types of contributions, from code and documentation to prompt design and UI ideas.

## 🧠 Ways to Contribute

- 🛠 **Code**: Bug fixes, features, or backend/frontend improvements
- 📝 **Documentation**: Clarify instructions, improve setup guides
- 🎨 **Design**: UI/UX ideas, HTML digest layout suggestions
- 💬 **Prompts**: Help fine-tune GPT-4o system messages and templates
- 🧪 **Testing**: Try the system and report bugs or issues

## 🧰 Tech Stack

- **Backend**: Azure Functions, C#, .NET 9
- **Frontend**: React + Tailwind CSS (planned) or Blazor
- **AI**: Azure OpenAI GPT-4o
- **Voice**: Azure Cognitive Services Text-to-Speech
- **Automation**: Power Automate
- **Storage**: SharePoint Online, Supabase (optional)

## 🚀 Getting Started

1. **Fork** the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/briefly.git
   ```
3. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes and commit:
   ```bash
   git commit -m "Add new feature"
   ```
5. Push to your fork and create a **Pull Request**

## 📄 Code Style

- Follow standard .NET naming conventions (PascalCase, camelCase)
- Keep frontend clean and modular (components, utils, styles)
- Comment complex logic — especially AI prompt templates and transformers

## 🧪 Testing

If possible, test your changes locally or via Azure Function emulator. Leave test output if available.

## 💡 Need Help?

Open an [Issue](https://github.com/techbuzzz/briefly/issues) or start a [Discussion](https://github.com/techbuzzz/briefly/discussions) — we’re here to help!
